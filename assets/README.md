# assets/ — 开发期素材存档

> 项目已太监（见仓库根 README）。此目录是开发数字人功能期间实际使用过的素材存档，不再维护。

## skins/ — 皮肤素材（数字人形象，已废案）

每个子目录 = 一套皮肤；`.mp4` 为动态待机视频，`.jpg/.webp` 为静态图。

| 皮肤 | 内容 | 体积 |
|---|---|---|
| 小雅 | 20 段待机视频 + 1 张图 | ~32 MB |
| 小雅2 | 静态图 | <1 MB |
| 伊雷娜 | 待机视频 | 8 MB |
| 友利奈绪 | 待机视频 | 57 MB |
| 洛琪希 | 待机视频 | 22 MB |

全部为 1080p25 静音（已转码）。`.active.json` 为运行时状态，不入库。

## voices/ — 音色素材（语音模块，仍可用）

每个子目录 = 一个克隆音色：`ref_audio.wav`（16kHz 参考音频）+ `ref_text.txt`（对应台词）。

| 音色 | 说明 |
|---|---|
| 小雅 | 温柔陪伴型 |
| 兔娘 | 活泼撒娇型 |
| 阿七 | 汇报导航型 |
| 麻勒勒 | 元气少女型 |

`.active.json` 为运行时状态，不入库。上传新音色可直接用 `ui-voice` 插件音色管理面板。
