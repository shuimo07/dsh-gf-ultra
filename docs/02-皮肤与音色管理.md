# 02 - 皮肤与音色管理

DSH 插件新增两个管理面板，都是工具栏按钮 + 弹窗。

## 皮肤管理（🎨）

目录结构：

```
assets/skins/<皮肤名>/
├── bg/     # 待机素材：视频（播放循环）或图片（10s 轮换）
└── talk/   # 说话动画：视频（朗读时切换播放）
```

API：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/skins` | 皮肤列表 + 当前激活 |
| POST | `/api/skins/create` | 新建皮肤（自动建 bg/talk） |
| POST | `/api/skins/active` | 切换激活皮肤（持久化 `.active.json`） |
| POST | `/api/skins/upload` | 上传素材（bg 收视频+图片，talk 收视频） |

前端：皮肤面板打开期间每 15s 自动刷新；切换/上传后 `SkinController.bump()` 通知女友窗立即重载素材。

## 音色管理（🎵）

目录结构：

```
assets/voices/<音色名>/
├── ref_audio.wav   # 16kHz 单声道参考音频（声音克隆源）
└── ref_text.txt    # 参考音频的逐字文本（克隆质量关键）
```

API：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/voices` | 音色列表 + 当前激活 |
| POST | `/api/voices/active` | 切换音色（下次朗读生效，桥接自动重载 TTS） |
| POST | `/api/voices/upload` | 上传参考音频（mp3/mp4 等自动转 16k WAV）+ 文本 |

切换音色机制：`ensure_tts()` 对比当前激活音色，变化时丢弃已加载的 TTS handler，下一次 `/api/tts` 用新参考音频重建。

## 换装/换声流程

1. 🎨 新建皮肤 → 自动切换 → 上传待机/说话素材
2. 🎵 上传参考音频（3-60s 干净人声）+ 逐字文本 → 自动成为可用音色
3. 一键切换，全部即时生效
